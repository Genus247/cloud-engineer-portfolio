02 / ABOUT ME

Curiosity builds capability.

I am an aspiring Cloud Engineer with a strong interest in designing, building and managing secure, scalable and reliable cloud infrastructure using Amazon Web Services (AWS).

My cloud engineering journey combines structured learning with practical, hands-on projects. I have gained experience working with AWS services including Amazon S3, CloudFront, IAM, AWS Lambda, API Gateway, CloudWatch and AWS WAF.

I have also explored website hosting, serverless architecture, identity and access management, automated deployments using GitHub Actions and integrating AWS services to build functional cloud solutions.

I am particularly interested in cloud infrastructure, DevOps practices, automation, security and continuous improvement. My goal is to develop the skills required to design and support reliable cloud environments.
